## Project Identity

## Source of Truth
The only approved product documents are:
1. PRD.md
2. UI-GUIDELINE.md
3. IMPLEMENTATION_PLAN.md

## Operating Rules
- Do not implement features outside the approved PRD.
- Do not change visual direction without approval.
- Do not introduce a framework or dependency without approval.
- Keep HTML, CSS, and JavaScript modular and readable.
- Use mock data only until backend integration is explicitly approved.
- Every phase requires explicit user approval before execution.
- If requirements conflict, stop and ask for clarification.
- Preserve existing behavior when modifying a feature.
- Validate responsive behavior and console cleanliness before completion.

## Approval Gate
Before starting each phase, provide:
- Scope
- Files to be changed
- Expected output
- Risks or assumptions

Proceed only after the user explicitly approves.
