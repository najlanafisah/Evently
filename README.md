# Evently

Evently is a web-based event management dashboard prototype designed to help administrators organize event data, registrations, registrants, and attendance through a clean and modern interface.

## Features

- **Dashboard**: Overview interface for event management.
- **Event Management**: Interface for viewing and organizing event data.
- **Registration Management**: Dedicated page for registration workflows.
- **Registrant Management**: Interface for viewing registrant information.
- **Attendance Management**: Dedicated attendance management page.
- **Responsive Layout**: Sidebar navigation and adaptable interface.
- **Mock Data**: Sample data for demonstrating the application's interface and interactions.

## Tech Stack

- **HTML5**: Web page structure.
- **CSS3**: Styling, layout, and responsive design.
- **JavaScript**: Navigation, UI interactions, and application logic.
- **Vercel**: Web deployment and hosting.

## Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code or another code editor.
- A local development server, such as the Live Server extension.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/Evently.git
   cd Evently
   ```

2. Open the project in your code editor.

3. Run `index.html` using a local development server.

4. Open the provided local URL in your browser.

## Project Status

Evently is a front-end prototype built with HTML, CSS, and JavaScript. It uses mock data to demonstrate the interface and navigation. Backend integration, authentication, and payment functionality are outside the current implementation scope.
